Big-O Detektivi

Eyni təhlil iki üsulla: funksiyanın addımlarını sayır (deterministik, dəqiq) və ya perf_counter ilə vaxtı ölçür (istənilən funksiya üçün, amma küylüdür). Vaxt ölçməsində O(1) ilə O(log n) və O(n) ilə O(n log n) cütləri bir-birindən ayrılmır, belə hallarda iki variant göstərilir.

Metodologiya

Hər ölçmə üçün ən yaxşı nəticə götürülür (minimum), zibil yığıcı ölçmə zamanı söndürülür, çox sürətli əməliyyatlar bir neçə dəfə təkrar edilib bölünür. Bufer hər dəfə tam doldurulduqdan sonra ölçülür. Python 256-dək tam ədədləri keşlədiyi üçün ölçmələr n ≥ 2048-dən başlayır. Yaddaş tracemalloc ilə ölçülüb, bütün ölçmələr eyni obyektə istinad edir, yəni göstərilən rəqəm strukturun öz xərcidir.
